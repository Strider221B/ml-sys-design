# Requirements

## Machine Learning (ML) System Design in 2026

### Interactive Sandbox Architecture Builder

1. Drag-and-Drop Canvas: Users connect visual blocks representing ML infrastructure (e.g., Feature Stores, Vector Databases, Model Registries, Inference Gateways).
2. Live Trade-Off Calculator: Changing a component automatically updates a simulated system impact matrix. Swapping batch prediction for streaming inference should immediately update latency benchmarks and compute costs.
3. Agentic & RAG Templates: Pre-built base canvases for cutting-edge patterns: Multi-Agent orchestration, hybrid search RAG, and LLM guardrail routing.

### Interactive Case-Study Library
* Diverse Industry Blueprints: Step-by-step interactive breakdowns of production systems:  
	* E-commerce: Real-time personalized news/clothing ranking  
	* Security: Real-time streaming fraud detection  
	* GenAI: Enterprise-grade knowledge retrieval utilizing Vector Databases  
* Failure Mode Simulator: A "Break the System" mode where data drift, training-serving skew, or LLM hallucination spikes are introduced, prompting users to select the correct monitoring or retraining strategy. 

### AI Interview Simulator (2026 Standard)
* Dynamic Prompting Engine: Simulates open-ended whiteboard design loops (e.g., "Design a YouTube recommendation framework").
* 6-Step Framework Enforcement: Forces users through the standardized production lifecycle:
	1. Clarifying Requirements
	2. Data Ingestion & Feature Engineering
	3. Model Selection & Training
	4. Model Evaluation (Offline vs. Online A/B testing)
	5. Serving & Scalability
	6. Monitoring & Retraining Loops
* Multimodal Evaluation: Evaluates spoken or drawn layout inputs, providing direct feedback on system bottlenecks or missing architectural steps.

### Chaos Engineering & Failure Sandbox
* Adversarial Playground: The app presents a flawless architectural layout generated by an LLM (like Gemini Argon). The user's job is to inject faults (e.g., network partitions, token-limit overflows, or race conditions) to expose the model's blind spots.
* Agent Cascading Loop Simulator: Interactive scenarios where multi-agent systems enter infinite execution loops, drain API budgets, or hallucinate tool parameters. Users must design deterministic control hooks and circuit breakers to halt the cascade.
* Live Debugger for Edge & Quantised Deployments: Simulated environments where users must optimize a model to fit onto a low-tier edge device (e.g., simulating extreme memory constraints, thermal throttling, and precision loss from FP32 to INT4 quantization).

### FinOps & GPU/TPU Unit Economics Calculator

* Compute Budget Simulator: Users are given a target queries-per-second (QPS) goal and a strict monthly budget. They must dynamically allocate resources between proprietary API routing, open-source hosting (vLLM), speculative decoding setups, and prompt caching.
* Hardware Bottleneck Profiler: Interactive exercises matching specific ML workloads to optimal compute choices (e.g., evaluating when to choose NVIDIA H100s, Google TPUs, or AMD MI300X chips based on memory bandwidth vs. raw FLOPS).

### Advanced Data Alignment & Curation Engine

* Synthetic Data Pipeline Auditor: Users evaluate batches of LLM-generated training data to spot subtle systemic biases, repetitive phrasing patterns, and low-diversity edge cases that ruin model alignment.
* Human-in-the-Loop (HITL) Workflow Designer: Visual canvas for building optimal reward systems and filtering gates where human feedback can most efficiently correct drifting production models.

### Gamified Failure Modes: "The Chaos Monkey" Engine

Instead of just static lessons, introduce a dynamic engine that actively tries to break what you build.
* Production Incident Roulette: A mode that triggers unexpected engineering disasters in real-time (e.g., "Your vector database provider just updated their API, causing a 40% latency spike. Fix the code/architecture before your error budget runs out").
* The "Gemini Argon" Adversarial Reviewer: An embedded LLM agent that scans your completed architecture and code, finds the exact edge case you missed, and generates a custom workload packet specifically designed to crash your system.

### Industry-Grade Telemetry & Observability Dashboard

Modern engineering relies heavily on reading charts to diagnose system issues. Your app should train you to look at the right data signals.
* Grafana/Prometheus Style Views: Add a toggleable tab that switches the clean app UI into a realistic operations dashboard tracking metrics like p99 latency, token-to-time-to-first-byte (TTFT), GPU memory fragmentation, and dead-letter queue sizes.
* Log Trace Analysis Game: The app shows you raw, messy text logs from a simulated system crash. You must parse the log trace to identify whether the issue is a software bug, a network timeout, or a hardware failure.

### Regulatory, Compliance, & AI Safety Simulator

In 2026, building a system that is cheap and fast isn't enough; it must also be compliant and legally secure.
* EU AI Act & Data Privacy Gates: Scenarios where you must design data pipelines that enforce strict user deletion requests (Right to be Forgotten) across machine learning weights and embedded vector stores.
* Copyright & Guardrail Auditing: A simulator where users must build ingestion filters to catch and block copyrighted training data or toxic prompt injection attempts before they hit the core processing layers.

### Interactive "Resume-Builder" Architecture Exporter

Turn the app into a tool that directly lands you your next role by proving your practical expertise.
* One-Click Portfolio Generation: The app compiles your high-level system canvas and low-level code solutions into clean, beautiful interactive portfolios hosted via GitHub Pages.
* Production Manifesto Auto-Gen: The system generates a structured write-up explaining why you chose specific hardware, how you optimized the unit economics, and how you protected against failure loops—perfect for attaching to job applications.

### Mathematical Objective & Alignment Formulation Workspace

When models train themselves, the human's job is to define exactly what success looks like without causing unintended side effects.
* The Reward Function Sandbox: Users write mathematical loss functions or alignment reward functions (e.g., for RLHF or DPO loops). The simulator runs these functions against an agent population to expose how the model might "game the system" (reward hacking).
* Multi-Objective Optimization Matrix: Challenges where users must balance conflicting math constraints (e.g., maximizing user engagement while minimizing toxic content drift and keeping compute costs below a fixed threshold).

### Data Archaeology & Contamination Auditing Suite

The core bottleneck of 2026 data science is the quality, clean alignment, and isolation of data.
* Data Leakage/Contamination Scanner: The app provides a massive synthetic dataset. Users must write programmatic tests to detect subtle test-set leakage, data poisoning, or label corruption that standard statistical metrics overlook.
* Information Density Filter: Data scientists build custom pipelines to slice away redundant, low-quality data from training logs, focusing purely on identifying high-value, high-entropy edge cases.

### Causal Inference & Counterfactual Lab

Predictive correlations are commoditized. The premium value is now in understanding causality to drive business interventions.
* Causal Graph Canvas: A simulator where users map out DAGs (Directed Acyclic Graphs) to isolate true confounding variables rather than relying on raw correlation matrix mappings.
* Synthetic A/B Variance Engine: Practice modules utilizing advanced techniques like CUPED or Synthetic Controls to reliably measure subtle experimental lifts in environments with highly volatile traffic.

## Core Curriculum Modules (2026 Focus)

### Module 1: Classical Data & MLOps Infrastructure
* Feature Engineering Scales: Designing low-latency feature stores for real-time reads vs. batch offline training pipelines.
* Traditional Scalability: Load balancing, distributed caching, message queues (Kafka), and database sharding patterns tailored for high-volume data streams.

### Module 2: Generative AI & Foundation Models
* Vector Infrastructure: Designing high-throughput Retrieval-Augmented Generation (RAG) loops and benchmarking semantic search indexing.
* LLM serving optimizations: Visualizing architectures utilizing speculative decoding, vLLM routing, and multi-tenant prompt caching to handle latency challenges.
* Agent Orchestration: Designing stateful agent graphs, tool-calling loopbacks, and multi-agent consensus networks.

### Module 3: Production Engineering & System Metrics
* Experimentation Architecture: Designing robust online evaluation frameworks (A/B testing, multi-armed bandits, CUPED for variance reduction).
* Cost & Latency Auditing: Designing real cost benchmarks mapping hardware footprint (GPU/CPU) against target throughput requirements.

### The 2026 Data Science Curriculum Transformation

* From Fitting Models to Prompt & Pattern Mining: Evaluating how to structure input data contextually so that giant models process reasoning tasks flawlessly without fine-tuning.
* Statistical Drift Auditing: Detecting semantic drift in unstructured vector spaces—monitoring when incoming customer queries shift away from the model’s static training distribution.

## Non-Functional & Technical Requirements
* Low-Latency Render: Canvas updates and visual flow computations must execute under 100ms to provide a seamless interactive teaching experience.
* State Serialization: Architectures designed on the canvas must export cleanly to standardized JSON schemas or declarative formats (like Terraform/Kubernetes manifests) so students can save their work to GitHub portfolios.
* Accessibility (WCAG 2.1): High-contrast modes for complex architecture blocks, full keyboard navigability for the interactive canvas, and localized universal terminology.
* Deterministic Simulation Engine: The back-end must accurately calculate real-world hardware costs, latency impacts, and failure probabilities based on empirical 2026 infrastructure benchmarks.
* Interactive Visual Profiler: Complex performance telemetry (e.g., flame graphs of memory usage, attention heads, or streaming data queues) must render seamlessly at 60 frames per second on mobile or desktop devices.
* Plug-and-Play Scenarios: The learning modules must follow an open-ended schema (YAML/JSON) allowing rapid deployment of new, real-world tech stack failures as they happen in the industry.
